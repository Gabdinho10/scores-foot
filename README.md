# Scores Foot

Application web mobile : scores en direct, calendriers, classements, buteurs, compositions et pronostics.
Données : API-Football (api-sports.io).

- La clé API n'est **jamais** dans le code : elle se saisit dans l'application (icône ⚙️) et reste sur l'appareil.
- Fichiers : `index.html` (l'application), `manifest.webmanifest` + `sw.js` + icônes (installation sur l'écran d'accueil).
- Hébergement : GitHub Pages.
